HabitStacker
Stack habits and create streaks to promote a healthier and more productive daily life

HabitStacker is a habit-tracking app built around the concept of habit stacking — pairing habits together in sequences to make routines easier to maintain. Core features include stackable daily habits, streak tracking, push notification reminders, and a weekly stats overview.

HabitStacker is built with React Native (Expo) using React Navigation for screen flow and AsyncStorage for on-device data persistence. State is managed via React Context API, with Expo Notifications handling daily reminders — no backend or login required.
