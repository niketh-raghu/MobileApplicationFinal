Screen Feature Summary
Screen Core Features Tech / Notes
Splash / Onboarding App logo, tagline, 4 feature highlights, Get Started CTA, restore option. Skipped on return visits via stored flag. AsyncStorage firstLaunch flag
Home / Today View Personalized greeting with date, 7-day streak banner, habit list (emoji + name + category + reminder time), progress bars, checkboxes with completion timestamps, and done count badge. React Context, AsyncStorage daily state
Add / Edit Habit Habit name input with cursor, emoji icon picker, category chips (Health / Fitness / Focus / Skills), frequency selector (Daily / Weekdays / Weekly), reminder time picker, and habit stacking toggle with linked habit preview. Expo Notifications, Context API
Habit Stack View Stack name and linked habit count, progress bar, numbered chain: completed steps (green ✓), next step highlighted in purple with CTA, locked future steps grayed with 🔒 icon. Add-to-stack button. React Navigation, Context state
Weekly Stats Day-labeled bar chart (Mon–Sun) showing daily completions/total, 4-up stat cards (streak, completion %, habits done, total time), and best-habit highlight card for the week. Aggregated from AsyncStorage weekly log
Reminders Per-habit notification cards (emoji, habit name, schedule label, active/paused badge) with on/off toggles. Tap to edit time. Add new reminder button. Expo Notifications API scheduling
